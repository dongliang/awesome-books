# Awesome Books

一个为了方便了解国内外大学里都开展了哪些具体的学科。后来又针对大学里不开展的学科，增加了对应的畅销书作为补充，旨在没事的时候翻看一下，希望可以对提升认知起到一些意外的收获。

**在线访问**：<https://dongliang.github.io/awesome-books/>

## 内容规模

- 16 个大门类
- 756 个核心主题
- 915 条资料条目

学科分类骨架参考 UNESCO ISCED-F、OECD FORD 与教育部《研究生教育学科专业目录（2022年）》。

大学课程之外的内容用畅销书补充，并标注了这些内容没有开展大学课程可能的原因（如：必须通过实践掌握、涉及创伤与敏感经历、规则因地区而异等）。医学、法律、财务与安全等问题请咨询专业人士，实践类知识仍需动手练习。

## 使用

- 顶部搜索框：按门类、主题、作者、资料或原因搜索
- 「收录来源」：单独查看大学学科或畅销书
- 原因标签：多选筛选畅销书内容
- 支持深色模式，移动端已适配（头部信息收进可折叠面板）

## 目录结构

```
src/     网页本体（index.html + 知识树数据 JS）
data/    书籍简介数据与书单源文件
tools/   数据同步脚本
```

## 部署

推送到 `main` 后，GitHub Actions 自动把 `src/` 发布到 GitHub Pages（已设置 `noindex`，不做搜索引擎收录）。
